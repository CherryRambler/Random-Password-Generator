# Random Password Generator

A simple and intuitive web application that generates secure random passwords with a single click.

## Description

The Random Password Generator is a lightweight JavaScript application designed to help users create strong, random passwords quickly and easily. The generator produces 14-character passwords containing a mix of numbers, uppercase letters, and special characters (!@#$%^&*()), ensuring robust security. With a single click of the "Generate Password" button, users get a new random password. The application also includes a convenient copy-to-clipboard feature that notifies users when the password has been successfully copied.

## Getting Started

### Dependencies

This project requires minimal dependencies and can run on any modern web browser:

* Any modern web browser (Chrome, Firefox, Safari, Edge, etc.)
* Internet connection (for Font Awesome icons from CDN)
* No installation or build tools required

### Installing

1. Clone or download the project files
2. Navigate to the Random-Password-generator folder
3. No additional installation steps required - all files are ready to use

## Executing Program

To run the Random Password Generator:

1. Open the `index.html` file in your web browser
2. Click the **"Generate Password"** button to create a new random password
3. The password will appear in the input field
4. Click the **copy icon** (📋) to copy the password to your clipboard
5. A "Password Copied" notification will appear in the bottom-right corner for 2 seconds

## How It Works

* **Password Generation**: Click the generate button to create a 14-character password
* **Character Set**: Passwords include numbers (0-9), uppercase letters (A-Z), and special characters (!@#$%^&*())
* **Copy to Clipboard**: Click the copy icon to copy the password to your clipboard
* **Visual Feedback**: A notification appears when the password is successfully copied

## Help

**The password won't copy to clipboard:**
* Make sure you've generated a password first (the input field should not be empty)
* Try clicking the copy icon again
* Check that your browser allows clipboard access

**Browser Compatibility Issues:**
* Ensure you're using an updated version of your browser
* Try a different browser if the application doesn't work
* Clear your browser cache if experiencing issues
